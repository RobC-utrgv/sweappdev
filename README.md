# campus-connect
Campus Connect is a social application specifically designed for students at UTRGV. It's a mixture of campus-wide social hub, event discovery and an interactive campus map.  The goal is to help students connect, inform, and discover . 

## Project Objectives
- Practice the full Software Development Life Cycle (SDLC)
- Apply Agile methodologies in a team setting
- Implement features based on real-world student needs
- Emphasize code quality, modularity, testing, and documentation

---

## Core Features
- **Social Feed:** Create and delete posts; like/comment and interact with other students.
- **Events:** Browse, create, and join events.
- **Campus Map:** A map showing live events and key campus locations.
- **User Profiles:** Basic student profiles with editable information.
